# Zia-E-Madni Travel & Tours

Static website for Zia-E-Madni Travel & Tours. The site is served from `index.html`; no framework, build step, or package installation is required.

## Deploy with Cloudflare Pages

1. In Cloudflare, choose **Create application** > **Pages** and connect your GitHub account.
2. Select `ziaemadnitravelandtours-boop/zia-e-madni-travel-tours` and the `main` branch.
3. Set **Framework preset** to **None**.
4. Leave the **Build command** empty and set **Build output directory** to `.`.
5. Create and deploy the application.
